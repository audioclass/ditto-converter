# Third-party software and source rights

The MIT license covers original Ditto Converter code and the original icon generated by `scripts/generate-icon.py`. It does not replace dependency or helper licenses. No external artwork/fonts or audio recordings are included. Audio tests synthesize tones/PCM and use explicitly controlled helper fixtures.

## Compiled application dependencies

Cargo/npm lockfiles pin resolution. CI emits declaration inventories and available license/notice texts. The inventory is a build/all-platform superset, not a claim that every dependency ships. Relevant MPL-2.0 files retain MPL rights and source-availability requirements; their exact package/version/source locations are listed in the inventory. Obtain unmodified crate source from the registry version identified by Cargo.lock or from paired source archives when provided. The sole dependency source edit is the exact build-local `objc2-core-foundation 0.3.2` reconstruction described below; all other dependency source bytes remain unchanged. Missing notices or source information must be resolved before downstream distribution; inventory generation alone is not legal clearance.

## Bounded macOS dependency variant and notices

Before **any Cargo resolution/build/test**, run `node scripts/prepare-remediation.mjs` (Python 3 standard library required). This verifies the immutable crates.io archive, original file, recipe and replacement SHA-256 values, reconstructs only beneath `.work/dependency-remediation`, and replaces only `src/user_notification.rs`. The unused `check_box_checked`, `secure_text_field` and `pop_up_selection` helpers are omitted; generated external declarations, ABI types, geometry/range implementations and all other crate bytes are unchanged. Cargo.toml deliberately patches this exact version to that path; Cargo.lock therefore removes its registry source/checksum. The original checksum remains mandatory in `scripts/remediation/recipe.json` and the collector. No global Cargo cache is modified. See `scripts/remediation/README.md` for reproduction, verification and removal.

The four MIT-only packages (`block2 0.6.2`, `objc2 0.6.5`, `objc2-encode 4.1.0`, `objc2-foundation 0.3.2`) retain both authentic unchanged recovered Steven Sheldon and later Mads Marquart MIT grants, plus the pinned upstream declaration. They are **not** relabeled Zlib. Six independently declared triple-option packages (`dispatch2 0.3.1`, `objc2-app-kit 0.3.2`, the reconstructed `objc2-core-foundation 0.3.2`, `objc2-exception-helper 0.1.1`, `objc2-quartz-core 0.3.2`, `objc2-web-kit 0.3.2`) use their already-granted Zlib alternative and retain the authentic upstream text. Altered CoreFoundation source is plainly marked. Exact immutable sources, package mappings and SHA-256 values are in `scripts/ci/notice-pins.json` and `scripts/remediation/notices/provenance.json`; no generic grant is substituted.

The specific Apple BSD notice from WebKit commit `ed6dc7d8e3a5e1cf4332cbeb55ded19391dacbf6`, `Source/WebKit/UIProcess/API/Cocoa/WKWebView.h`, is conservatively packaged with `objc2-web-kit 0.3.2`. It covers the identified matched header prose, not every SDK header or the entire Rust dependency. The bounded engineering basis retains functional macOS interoperability declarations and OS-provided frameworks, removes the three unused notification conveniences, and does not distribute an SDK, full vendor tree or dependency rustdoc. This is not a blanket legal warranty.

Only those ten exact reviewed versions change notice status; other unresolved objc2-family supersets remain unresolved and fail closed if included. The collector accepts CoreFoundation only with its explicit verified reconstructed source identity, and records original/archive/replacement/recipe/tree provenance. Public source export includes the recipe, tiny replacement and unchanged notices, **never** the full reconstructed crate/cache/source-doc output. Existing MPL/LGPL corresponding-source duties remain independent. The combined private native Mac rebuild and exact packaged notice/source-variant checks passed on October 21, 2026 EDT (273 native inputs, zero failures, five MPL archives paired). This supersedes the earlier implementation-only remediation state, not historical failed binaries. Fresh combined-source Windows regression and an owner release decision remain required. Existing macOS upload restrictions remain unchanged; collector success is not blanket legal certification or upload authorization.

## Offline FFmpeg/ffprobe

CI compiles independent executables from official **FFmpeg 8.1.3** source:

- Source: https://ffmpeg.org/releases/ffmpeg-8.1.3.tar.xz
- SHA-256: `7138d28c96d9d3e3af4ee3d8cad72741f8ffb40da90c1112235dea3ecd3178a3`
- Build: `scripts/ci/build-ffmpeg.sh`; exact configuration and compiler/import evidence accompany each artifact.
- License: LGPL-2.1-or-later for the scoped build, with GPL/nonfree/version3 and external codec autodetection disabled. Actual binaries are checked rather than inferring license from repository labels.
- License and compliance guidance: https://ffmpeg.org/legal.html

The paired download includes the exact unmodified source archive, relevant license texts, configuration/build scripts and checksums. Users may replace the independent helper executables with compatible builds. Do not redistribute only an extracted installer while discarding the corresponding source/notice package. One-day Actions retention is not a durable source offer; downstream distributions must retain the source with the binaries they distribute.

## Optional online components

The repository embeds version/hash/length pins, **not binaries**, for upstream yt-dlp 2026.08.19 standalone and Deno 2.9.7. The app downloads them directly from upstream only after opt-in. No live provider media acquisition is part of hosted CI.

- yt-dlp source/README: https://github.com/yt-dlp/yt-dlp/tree/2026.08.19
- Exact third-party notice list: https://github.com/yt-dlp/yt-dlp/blob/2026.08.19/THIRD_PARTY_LICENSES.txt
- Standalone PyInstaller distributions contain GPLv3+ components; source-repository Unlicense alone is not the binary license.
- Deno source/license: https://github.com/denoland/deno/tree/v2.9.7 and https://github.com/denoland/deno/blob/v2.9.7/LICENSE.md

Optional downloaded helpers retain their upstream rights. Their licensing, platform trust, signatures and upstream corresponding-source fulfillment are distinct from the MIT app grant. Rehosting/repackaging those binaries requires an exact-artifact review; this source repository does not rehost them. Independent signed component updates are not implemented; unknown external update manifests fail closed.
