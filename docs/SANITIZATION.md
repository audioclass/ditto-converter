# Source-publication scope

The public repository is a new source-only export with fresh history. It does not publish the mixed private working directory or rewrite that directory's history.

Included: original application code, synthetic tests, lockfiles, explicit CI/build scripts, an original generated icon, application license/notice, rewritten public documentation, and the explicitly permitted hash-pinned dependency reconstruction recipe, two-line replacement and authentic notices.

Excluded: private conversations/context, legacy source attachments, machine/account installation manifests, private filesystem paths/infrastructure details, runtime state, toolchains, caches, downloaded binaries, media, screenshots, logs, raw research captures and historical acceptance evidence. Full reconstructed crate/vendor trees, registry archives/caches, dependency rustdoc and SDK headers/framework stubs are not publication inputs; the exporter rejects these paths even if its allowlist is broadened. Required LGPL/MPL corresponding source is paired separately with binaries, not added as an unreviewed source-vendor export. No original attachment or private audit record is deleted.

Source and exact staged history are checked with a redacting secret scanner and a generated fake-token positive control. Findings must be reviewed, not hidden by ignoring entire lockfiles. A separate privacy pass examines paths/network identifiers and compares staged bytes against the actual saved publication credential without printing that credential. No scanner result proves absence of every possible secret.

The original icon is constructed locally from documented geometric primitives, with no external image or font inputs. Third-party license files and notices retain their own terms.
